# История изменений

## 1.3.1 — исправление вылета при распознавании

- Исправлен немедленный вылет по кнопке «Распознать»: обязательный `preContext` передаётся как пустая строка для отдельного слова.
- Ошибки подготовки и запуска распознавания обрабатываются в окне без потери штрихов.
- Добавлены два Android/JVM-теста с настоящим построителем контекста ML Kit и запуск этих тестов в GitHub Actions.
- APK подписан тем же ключом и устанавливается поверх предыдущих версий.


## 1.3

- Самостоятельное поле рукописного ввода: письмо пальцем или стилусом, отмена штриха, очистка, выбор распознанного варианта.
- Бесплатное распознавание ML Kit на устройстве после первоначальной загрузки английской модели.
- Убрана привязка рукописного режима к клавиатуре Samsung. Gboard менять не нужно.
- Распознанный ответ можно отредактировать до проверки; устаревшие результаты не меняют следующее задание.
- Сборка переведена на Gradle для подключения Android-библиотеки распознавания.

## 1.2

- Лавандовое меню выбора наборов вместо системного списка.
- Аккуратная стрелка с отступом в кнопке выбора.
- Экспериментальный рукописный ввод через клавиатуру Samsung (заменён в 1.3).

## 1.1
