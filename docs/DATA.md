# Данные и внешние компоненты

## Что хранит приложение

Имя ребёнка, наборы, учебный прогресс, правила наград, копилка и история просьб сохраняются в закрытом хранилище приложения на телефоне. PIN хранится в виде хеша с солью. Удаление приложения удаляет его локальные данные; для переноса предусмотрен файл резервной копии.

Файл набора `.maywords` содержит слова и описание набора. Файл `.maybackup` содержит учебные данные и копилку. Эти файлы передаются только по действию пользователя через системный выбор файла или меню отправки. Не публикуйте личные резервные копии в issues.

## Рукописный ввод

В версии 1.3 используется Google ML Kit Digital Ink Recognition. Штрихи обрабатываются на устройстве; приложение не отправляет почерк, правильные ответы заданий или содержимое наборов на собственный сервер. Поле не делает снимки экрана и не использует камеру. Незавершённые штрихи не сохраняются после закрытия окна.

Английская модель загружается с серверов Google после нажатия кнопки загрузки. По документации Google, SDK также собирает технические данные: сведения об устройстве и версии приложения, идентификаторы установки, метрики производительности, конфигурацию API, размеры входа/выхода, события, коды ошибок и выбранный язык. Передача выполняется по HTTPS.

Источники: [обработка цифрового почерка](https://developers.google.com/ml-kit/vision/digital-ink-recognition), [сведения о данных SDK](https://developers.google.com/ml-kit/android-data-disclosure), [условия ML Kit](https://developers.google.com/ml-kit/terms).

## Голос и мессенджер

Озвучивание выполняет установленный движок Android TextToSpeech с локальным английским голосом. Движку передаётся текст слова. Приложение не записывает голос ребёнка.

При отправке набора или просьбы о минутах пользователь выбирает мессенджер и получателя. Дальнейшая обработка относится к выбранному мессенджеру. Приложение не читает переписки и контакты. Family Link настраивается родителем вручную.

## Зависимости

- Android SDK и Android System WebView.
- Google ML Kit Digital Ink Recognition 19.0.0 и его транзитивные зависимости.
- jsdom 26.1.0 используется только для тестов и не входит в APK.

Сторонние компоненты распространяются на условиях их правообладателей. Условия сторонних компонентов не задают лицензию исходному коду этого проекта.
